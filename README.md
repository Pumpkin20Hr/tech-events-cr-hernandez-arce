## Descripción del proyecto

TechEvents CR es una aplicación web desarrollada con HTML, CSS y JavaScript que permite visualizar eventos tecnológicos disponibles en Costa Rica, consultar la cantidad de cupos disponibles y realizar inscripciones de manera interactiva utilizando manipulación del DOM y manejo de eventos.

El proyecto forma parte de la práctica de laboratorio sobre DOM, eventos y debugging con JavaScript.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Git
- GitHub
- GitHub Pages
- Chrome DevTools

---

## Características

- Visualización de eventos tecnológicos.
- Inscripción en eventos.
- Cálculo dinámico de cupos disponibles.
- Interacción mediante eventos de clic.
- Manipulación del DOM.
- Resaltado visual de elementos.
- Identificación y corrección de errores utilizando herramientas de depuración.
